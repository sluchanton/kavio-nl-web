# kavio.nl — сайт-визитка

Статическая страница, без сборки. Правится прямо в index.html.

## Файлы

- index.html — вся страница: разметка, стили и переключатель NL/EN внутри
- CNAME — нужен GitHub Pages, чтобы привязать домен. Не удалять
- favicon.svg, favicon-32.png, apple-touch-icon.png, icon-512.png — иконки
- og.png — картинка превью для WhatsApp, LinkedIn, Slack (1200x630)
- robots.txt, sitemap.xml — для поисковиков

## Деплой на GitHub Pages

1. Создать ПУБЛИЧНЫЙ репозиторий, например kavio-site. На бесплатном плане GitHub
   кастомный домен работает только с публичным репозиторием.
2. Залить в корень все файлы из этой папки.
3. Settings -> Pages -> Source: Deploy from a branch, ветка main, папка / (root).
4. Settings -> Pages -> Custom domain: вписать kavio.nl, Save.
5. В GoDaddy DNS добавить четыре A-записи на @:
   185.199.108.153
   185.199.109.153
   185.199.110.153
   185.199.111.153
   И поправить существующий CNAME www: вместо kavio.nl указать <username>.github.io
6. Вернуться в Settings -> Pages, дождаться зелёной галочки и включить Enforce HTTPS.
   Сертификат выпускается автоматически, обычно 15-60 минут, иногда до суток.

Записи MX, SPF, DKIM и DMARC при этом не трогаются — почта продолжает работать.

## WhatsApp

Кнопка в блоке контактов ведёт на wa.me/31616731384 — это +31 6 16 73 13 84.
Менять номер: одна строка в index.html, международный формат без плюса,
без пробелов и без ведущего нуля. Текст после text= это предзаполненное
первое сообщение, пробелы кодируются как %20.

## Правка текста

Каждый переводимый кусок лежит двумя строками подряд:

    <span data-lang="nl">нидерландский текст</span>
    <span data-lang="en">английский текст</span>

Меняются обе. Язык по умолчанию — нидерландский, выбор посетителя
запоминается в его браузере.

## Что дописать, когда появится KVK

В подвал (footer) строкой: KVK <номер>, BTW <номер>.
Для голландской аудитории это заметный сигнал доверия.
